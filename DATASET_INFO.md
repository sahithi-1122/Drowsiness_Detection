# Dataset Information — UTA-RLDD

## Source

**Dataset Name:** UTA Real-Life Drowsiness Dataset (UTA-RLDD)  
**Kaggle URL:** https://www.kaggle.com/datasets/minhngt02/uta-rldd  
**Original Paper:** Ghoddoosian, R., Galib, M., & Athitsos, V. (2019). *A Realistic Dataset and Baseline Temporal Model for Early Drowsiness Detection.* CVPR Workshop.  
**Download method:** `kagglehub.dataset_download("minhngt02/uta-rldd")`

---

## Dataset Description

The UTA-RLDD dataset consists of approximately 30 hours of RGB video recorded from 60 healthy participants. Each participant contributes one video per class, resulting in 180 videos total:

| Original Label | Meaning | Our Mapping |
|---|---|---|
| `active` (label 0) | Completely conscious and alert | **Alert** |
| `fatigue` (label 10) | Actively trying not to fall asleep | **Drowsy** |

> Note: The original dataset has a third class (`low_vigilance`, label 5). This project uses the binary mapping (active → Alert, fatigue → Drowsy) as the primary classification task.

| Class | Weight |

Class weights are used to counteract the ~65/35 imbalance during training.

## Preprocessing Pipeline

1. **Dataset discovery** — checks kagglehub cache (`~/.cache/kagglehub/datasets/minhngt02/uta-rldd/versions/2/`) and falls back to `ml_pipeline/data/`
2. **Image loading** — iterates `active/` and `fatigue/` subdirectories, accepts `.jpg`, `.jpeg`, `.png`, `.bmp`
3. **Stratified split** — `sklearn.model_selection.train_test_split` with `stratify=labels`, `random_state=42`
4. **YOLO dataset generation** — copies images into `data/yolo_dataset/{train,val,test}/{Alert,Drowsy}/`
5. **Upload decode** — `cv2.imdecode(np.frombuffer(bytes), IMREAD_COLOR)` → validated BGR array
6. **Color conversion** — BGR → RGB before YOLO inference (`cv2.COLOR_BGR2RGB`)

---

## Known Limitations

| Limitation | Details |
|---|---|
| Frame-level split | Frames from the same participant/video can appear in both train and test, potentially overstating accuracy. A participant-level split is recommended for final evaluation. |
| Source is video-based | Near-duplicate frames between train and test increase the risk of data leakage. |
| Class imbalance | ~65% Alert vs ~35% Drowsy; mitigated with class weights during training. |
